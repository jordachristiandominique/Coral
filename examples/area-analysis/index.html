Sky blue: quadrat | Violet: Hard Coral boxes | White +: Hard Coral | Gold +: unclassified remainder

Each box label shows its clipped area as a percentage of the quadrat. Individual percentages can overlap; total raw coverage counts shared areas only once.

Use HC Box (B) to click and drag a new Hard Coral box inside the quadrat. Draw in any direction; release to add it, or press Escape to cancel. Switch to Hand tool or Select coral boxes to move and resize it. Click a coral box to select it and drag to move; smaller boxes take priority where boxes overlap in Select coral boxes mode. Hand tool gives the newest coral box priority without a Layers panel. Drag a selected corner handle to resize. Use Edit quadrat or Edit markers for those separate modes; select a label for precise selection. Coverage and markers update immediately. In marker mode, drag the crosses within their regions. Keyboard: focus the preview, use Left/Right to select a marker, then Shift+arrow to move it. Marker movement does not change raw coverage. The percentage fields remain available for precise box edits; coordinates are relative to the whole image.

Marker allocation and limitations

Markers are distributed by non-overlapping area, with balanced patterns (three form a triangle). Remaining markers are unclassified, not automatically Abiotic. Boxes can include non-coral pixels; this is a detection-box estimate, not segmentation or independent point sampling.

Edit selected quadrat or box

Only the selected shape appears here. Right-click a coral box or its label to delete it. Ctrl+Z (Cmd+Z on Mac) undoes edits; Ctrl+Y (Cmd+Y on Mac) redoes them. Use the Undo/Redo buttons when typing in a field.

Only box portions inside the quadrat count. Overlaps count once. Estimates of 53% and 54% receive five Hard Coral markers; 55% receives six. The raw coverage is never replaced by the marker percentage.
